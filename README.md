# 서울시 지하철 사고 원인 분석 및 안전 개선 방안

> 최근 5년간 발생한 서울시 지하철 안전사고를 유형별로 분석하고,  
> 이용량·역사 구조·시설 노후도·기상 조건을 결합해 사고 위험 요인과 개선 방향을 도출한 팀 프로젝트입니다.

---

## Project Summary

| 구분 | 내용 |
|---|---|
| 프로젝트 유형 | 데이터 분석 팀 프로젝트 |
| 분석 대상 | 서울시 지하철 안전사고 2,281건 |
| 분석 기간 | 2021.01 ~ 2025.06 |
| 분석 범위 | 사고 시간, 발생역, 이용객 규모, 역사 구조, 시설 노후도, 기상 조건 |
| 분석 방법 | 데이터 전처리, EDA, 상관관계 분석, 가설 검증 |

서울교통공사의 사고 데이터에는 사고 발생일, 발생역, 발생시간, 사고유형과 같은 결과 정보가 제공됩니다.

하지만 사고 결과만으로는 특정 사고가 왜 발생했는지, 어떤 조건에서 위험이 커지는지를 충분히 파악하기 어렵습니다.

이에 사고 데이터에 승하차 인원, 혼잡도, 승강장 구조, 역사 노후도, 안전문 정보, 기상 데이터를 결합하고 다음 질문을 중심으로 분석했습니다.

1. 사고는 특정 시간대와 환승역에 집중되는가?
2. 곡선 승강장과 연단 간격은 사고 위험을 높이는가?
3. 역사와 설비의 노후도는 사고 발생과 관련이 있는가?
4. 이용객 규모와 강수 조건은 사고 유형별로 어떻게 작용하는가?

## Accident Overview

전체 사고는 다음과 같이 분포했습니다.

| 사고 유형 | 사고 건수 |
|---|---:|
| 출입문 관련 | 771건 |
| 역 구내 사고 | 518건 |
| 열차 내 사고 | 423건 |
| 발빠짐 사고 | 341건 |
| 승강설비 관련 | 207건 |
| 기타 | 21건 |

사고 유형마다 발생 공간과 원인이 다르다고 판단하여,  
열차 내 사고·역 구내 사고·출입문 및 발빠짐 사고·승강설비 사고로 구분해 분석했습니다.

## Analysis Framework

사고 위험 요인을 세 가지 관점으로 구분했습니다.

### 시간적 요인

- 출근 및 퇴근 시간대
- 사고 발생 시각
- 월별·계절별 발생 패턴
- 강수 여부

### 공간적 요인

- 환승역 여부
- 호선 및 발생역
- 역별 이용객 규모
- 역사 면적과 동선 복잡도

### 구조적 요인

- 곡선·직선 승강장
- 승강장 유형
- 열차와 승강장 사이의 연단 간격
- 역사 및 설비 노후도
- 승강기와 안전문 설치 특성

총 12개의 세부 가설을 수립하고, 사고 유형별 EDA와 비교 분석을 통해 검증했습니다.

## Key Findings 🔎

### 1. 열차 내 사고는 혼잡·환승·곡선 구조가 중첩될 때 증가했습니다

열차 내 사고 상위 10개 역을 분석한 결과, 다음과 같은 특징이 나타났습니다.

| 주요 특징 | 분석 결과 |
|---|---:|
| 환승역 비중 | 90% |
| 곡선 승강장 비중 | 60% |
| 사고 집중 시간대 | 출근 시간대 |

이용객 수는 퇴근 시간대에 가장 많았지만, 열차 내 사고 비중은 출근 시간대에 가장 높았습니다.

이는 단순한 이용객 규모뿐 아니라 정해진 시간에 도착하려는 압박, 무리한 승차, 환승 승객의 집중이 함께 작용했을 가능성을 보여줍니다.

또한 곡선 구간에서는 열차 진입과 주행 중 차체 흔들림이 커질 수 있어, 혼잡한 열차 내부에서 승객이 균형을 잃을 위험이 증가하는 것으로 해석했습니다.

---

### 2. 역 구내 사고는 혼잡도보다 환승 동선의 복잡성과 관련이 있었습니다

역 구내 사고는 출근 시간대인 오전 8시 전후에 가장 높은 밀도를 보였습니다.

시간 구간의 길이를 고려해 시간당 사고 건수로 정규화한 결과, 출근 시간대의 사고 밀도는 기타 시간대보다 약 2배 높게 나타났습니다.

반면 혼잡도와 사고율의 상관계수는 `-0.38`로 나타났습니다.

즉, 단순히 사람이 많은 역보다 다음과 같은 구조적 특징을 가진 역에서 사고가 집중됐습니다.

- 여러 노선이 교차하는 대형 환승역
- 환승 거리가 길고 이동 방향이 복잡한 역사
- 계단, 통로, 승강장이 여러 층으로 연결된 역사
- 특정 구간에서 승객 동선이 합쳐지는 병목 구조

이를 통해 역 구내 사고는 전체 혼잡도보다 **승객이 실제로 이동하는 동선의 복잡성**을 함께 고려해야 한다고 판단했습니다.

---

### 3. 출입문·발빠짐 사고는 승강장 구조의 영향을 크게 받았습니다

전체 출입문 및 발빠짐 사고 중 곡선 승강장에서 발생한 사고는 약 `59.53%`였습니다.

곡선 승강장은 열차와 승강장 사이의 간격이 위치마다 달라질 수 있어, 승객이 간격을 정확하게 인지하기 어렵습니다.

특히 다음 조건에서 사고 위험이 높게 나타났습니다.

- 곡선 승강장
- 넓은 연단 간격
- 오래된 역사
- 복합식 또는 섬식 승강장
- 환승 동선이 긴 역사

출입문 사고는 일평균 승하차 인원과 `0.36`의 양의 상관관계를 보였지만, 혼잡도와의 상관계수는 `0.11`로 낮았습니다.

반면 발빠짐 사고는 이용객 규모보다 곡선 선형과 연단 간격 등 **물리적 구조의 영향**이 더 큰 것으로 나타났습니다.

---

### 4. 승강설비 사고는 노후도·이용 부하·강수가 복합적으로 작용했습니다

승강설비 사고는 하나의 변수보다 여러 위험 조건이 결합될 때 증가하는 특징을 보였습니다.

분석 결과 다음과 같은 관계가 확인됐습니다.

- 노후도가 높은 구간에서 평균 사고 건수가 증가
- 노후 역사 중 일부 고위험 역이 전체 평균을 크게 상승시킴
- 승객 수와 설비 수가 많은 대형 역사에서 관리 부담 증가
- 강수일에는 대부분의 시간대에서 사고 비율이 상승
- 역사 면적과 승강기 개수 사이에 높은 상관관계 존재

모든 노후 역사가 위험한 것은 아니었지만,  
노후도와 높은 이용객 수, 많은 설비 수가 동시에 나타나는 역사에서는 사고 위험이 커졌습니다.

따라서 승강설비 사고는 단순한 노후 시설 교체보다, 역사별 이용 부하와 기상 조건을 함께 고려한 관리가 필요하다고 판단했습니다.

## Safety Improvement Plan 🛠️

분석 결과를 바탕으로 개선 방향을 세 가지 영역으로 구분했습니다.

### 시설 개선

- 고위험 곡선 승강장에 자동 발판 또는 Gap Filler 확대 설치
- 열차와 승강장 사이의 연단 간격 축소
- 노후 역사의 통로 및 환승 동선 개선
- 열차 내부 수직 지지봉 확충
- 곡선 구간의 차량 흔들림을 줄이는 설비 검토

### 운영 최적화

- 출근 시간대 주요 환승역에 안전 인력 집중 배치
- 사고 다발 역의 병목 구간과 교차 동선 분리
- 곡선 승강장과 넓은 연단 간격 구간의 시각·청각 안내 강화
- 강수일 승강설비 및 바닥 상태 사전 점검
- 사고 유형과 역사 특성에 따른 맞춤형 관리 기준 운영

### 데이터 기반 관리

- 실시간 승강장 혼잡도 및 설비 상태 모니터링
- 강수와 이용객 변화를 반영한 동적 안전 관리
- 역별 위험 요인을 결합한 사고 위험 지수 개발
- 사고 다발 역사 중심의 우선 점검 체계 구축
- 실시간 운영 데이터를 활용한 예측 모델 고도화
